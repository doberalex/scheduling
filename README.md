# scheduling

Telegram bot project on Python.

Telegram-бот для управления расписаниями пятниц и воскресений. Правила перенесены из `scheduling.php`: лимиты по типам дней, запрет первых двух слотов, одиночное участие, только воскресенье, интервал между назначениями и проверка итогового расписания.

## Создание бота в Telegram

1. Откройте Telegram и напишите `@BotFather`.
2. Выполните `/newbot`.
3. Задайте имя и username бота.
4. Скопируйте токен в файл `.env`.

## Установка

```bash
cd /home/d/doberalex/public_html/scheduling
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:

```bash
BOT_TOKEN=telegram_token_from_botfather
ADMIN_IDS=62602216
TIMEZONE=Europe/Moscow
DB_HOST=localhost
DB_PORT=3306
DB_USER=doberalex_tbotschedule
DB_PASSWORD=database_password
DB_NAME=doberalex_tbotschedule
```

Бот закрыт для посторонних: все команды и кнопки доступны только пользователям из `ADMIN_IDS` или `ADMIN_ID`; остальные получают предупреждение.

Все рабочие данные хранятся в MySQL. Бот сам создаёт таблицы при первом запуске:

- `schedule_participants`
- `schedule_limits`
- `schedule_participant_lists`
- `schedule_extra_dates`
- `schedule_months`
- `schedule_slots`
- `schedule_slot_participants`
- `schedule_attendance_events`

Явная инициализация базы:

```bash
python3 scripts/init_db.py
```

## Команды

Основное управление сделано кнопками:

- `📅 График` - раздел графика.
- `📆 Показать график` - выбрать прошлый, текущий или следующий месяц.
- `⬅️ Прошлый месяц` - быстро показать прошлый месяц.
- `➡️ Следующий месяц` - быстро показать следующий месяц.
- `💾 Сохранить график` - сохранить месячный график в БД.
- `🔄 Пересохранить месяц` - полностью заменить не опубликованный график новым расчётом, отличающимся от текущего.
- `✏️ Редактировать участие` - выбрать месяц, дату и заменить список участников.
- `✅ Отметить участие` - отметить `✅` был, `❌` пропустил или `🟡` запас.
- `➕ Вне графика` - добавить участника не по графику.
- `📣 Опубликовать` / `📝 Не публиковать` - статус сохранённого графика.
- `⚙️ Настройки` - ограничения, лимиты и дополнительные даты.
- `🔢 Лимиты` - изменить лимит пятницы или воскресенья через кнопки.
- `👥 Участники` - список, добавление и удаление участников.
- `⛪ Назначить служителем` / `↩️ Убрать служителя` - изменить роль участника через выбор имени.

Служители хранятся в записи участника и продолжают участвовать в обычном расписании пятниц и воскресений. К пяти обычным назначениям каждого воскресенья добавляется одно отдельное назначение служителя (`⛪`). Несколько служителей чередуются по воскресеньям; очередь продолжается между месяцами. Один человек не может получить обычное и дополнительное назначение в один день. Дополнительные назначения не входят в лимит обычных участий и отдельно помечаются в истории статусов. Уже сохранённые графики при смене роли не переписываются.

При новом расчёте между любыми двумя назначениями служителя остаётся хотя бы одна свободная клетка. Бот подбирает равномерные варианты воскресной очереди и проверяет обычные участия вместе с дополнительными. Если при заданных ограничениях такого графика нет, сохранить его нельзя; в сообщении будут показаны причины.

При расчёте нового месяца бот учитывает сохранённый прошлый месяц: если участник был назначен 3 раза, в следующем месяце он получает приоритет на 2 участия, а участники с 2 назначениями получают приоритет на дополнительное участие.

`blockedStart` рассчитывается динамически для каждого формируемого месяца по двум последним датам предыдущего месяца. Если в этих датах есть отметки `✅`, берутся только участники с `✅`; если отметок `✅` нет совсем, считаются участвовавшими все участники этих дат независимо от статуса.

Участники, чьё имя начинается с `Гость`, не назначаются в плановый график и не выбираются при замене планового состава. Их можно добавлять через `➕ Вне графика`, отмечать участие и учитывать в статистике.

Перед сохранением и при показе сохранённого графика бот проверяет правила: лимиты дней, повторы, первые два слота, `singleParticipation`, `onlySunday`, интервал между участиями и наличие пятницы+воскресенья для обычных участников.

Обычный участник может быть назначен один раз за месяц без требования пятница+воскресенье. Если в прошлом месяце он уже участвовал один раз, в новом месяце один раз для него не допускается, чтобы одиночное участие переходило к другим участникам.

Slash-команды оставлены как запасной вход:

- `/schedule` - график на текущий месяц.
- `/schedule 7 2026` - график на указанный месяц.
- `/settings` - текущие настройки.
- `/participants` - список участников.
